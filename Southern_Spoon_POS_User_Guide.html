Cashier Operator Manual • Keyboard Navigation & Multi-Channel Workflows

v2.4 Keyboard Edition

This manual outlines the newly implemented keyboard-driven cashier controls, mandatory table floor selection, Takeaway & Delivery order queues, and custom hotkey punch-in workflows. By leveraging keyboard navigation, cashiers can process orders with speed, accuracy, and zero reliance on a mouse during peak hours.

Core Benefit: 100% Mouse-Free Cashier Speed

Cashiers can switch tables, select takeaway queues, punch numeric item hotkeys, pick Half/Full portions with arrow keys, adjust quantities, and settle bills via keyboard shortcuts in under 5 seconds per customer transaction.

1 Portion Selection & Quantity Controls (VariantModal)

When an item with multiple portions (such as Rice, Kottu, or Curries) is selected or punched by hotkey, the portion selector opens automatically.

  • Move between Portion Sizes (e.g. Half Portion vs. Full Portion) ↑ Up ↓ Down
  • Adjust Portion Quantity (Add or subtract portions) ← Left (-1) → Right (+1) or - / +
  • Direct Numeric Quantity Punch (Instantly sets quantity) 0 – 9
  • Confirm Portions & Add to Order Enter ↵
  • Dismiss / Cancel Modal Esc

* Note: If typing into the custom kitchen instruction box, arrow keys remain inside the text cursor to prevent interference.

2 Dining Floor & Table Selection (Dine-In Mode)

For Dine-In orders, cashier table selection is mandatory. The dining floor layout opens automatically whenever the Dine-In tab is selected without an assigned table.

3 Multi-Channel Queues (Takeaway & Delivery)

Takeaway walk-ins and delivery dispatch orders run on separate multi-cart queue slots (e.g. TK-01 to TK-12 and DL-01 to DL-12 for Uber Eats, PickMe, and Direct Delivery). Each queue slot saves its own shopping cart independently!

  • Open Queue Dashboard Click Queue in header or top-right cart banner
  • Toggle Takeaway ⇄ Delivery Channels Tab
  • Navigate between Queue Slots ← → ↑ ↓
  • Select & Open Active Queue Cart Enter ↵
  • Exit Queue Modal Esc
Sri Lankan Delivery Platforms Supported

Delivery queues display dedicated badges for Uber Eats (Green), PickMe Food (Amber), Direct Phone Order (Blue), and In-House Rider (Purple) with customer name and rider tracking.

4 Live Order Cart Keyboard Controls (OrderCart)

On the main POS ordering screen, cashiers can adjust line items in the active order cart without touching the mouse.

  • Select / Move across Cart Items ↑ Up ↓ Down
  • Increase / Decrease Item Quantity ← (-1) → (+1) or - / +
  • Remove Item from Bill Delete
  • Settle / Open Payment Modal Click Settle / Pay button

5 Rapid Numeric Hotkeys & Admin Hotkey Manager

Cashiers can type any menu item's assigned number directly on the keyboard to add it instantly to the current bill.

How Cashiers Punch Hotkeys

Type the item code on the number row or numpad. An on-screen HUD appears showing the live matching menu dish:

Example: Type [ 1 ] [ 0 ] [ 1 ] → Enter ↵

If the item has portions, the portion modal opens automatically for instant ↑/↓ choice.

Admin Hotkey Manager

To customize or reassign hotkey numbers:

  1. Click the ⚡ Hotkeys button on the top POS header.
  2. Enter Manager PIN: 1234.
  3. Assign 1, 2, or 3-digit codes next to high-volume items (e.g., Short Eats, Kothu, Rice).
  4. Click Save & Apply Hotkeys.

6 Settlement & Payment Modal Shortcuts (PaymentModal)

When the bill is ready for payment, the settlement modal supports keyboard-based method switching and cash tenders.

  • Cycle Payment Method (Cash ⇄ Card Terminal ⇄ LankaQR) ← Left → Right or keys 1 / 2 / 3
  • Quick Cash Tender Adjustment (In Cash Mode) ↑ (+Rs. 500)   ↓ (-Rs. 500)
  • Complete Payment & Trigger Thermal Printer Enter ↵
  • Cancel / Exit Settlement Esc
